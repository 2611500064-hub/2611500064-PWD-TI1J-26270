## Pertemuan 4 - CSS3 Layout dan Responsive Web Design
Pengembangan
- Perubahan yang dilakukan: [Menambahkan tata letak responsif menggunakan Media Query @media (min-width: 768px) dengan CSS Grid 2 kolom pada <main>, mengatur perataan komponen navigasi header, pemformatan kartu/seksi (#home, #about, #contact), serta penyesuaian gaya elemen formulir dan tombol.]

- Commit dan push GitHub: [Melakukan commit perubahan CSS layout responsif dan melakukan push seluruh berkas proyek ke repositori GitHub.]

##  Pengujian
•Perangkat bergerak: [Viewport < 768px (misal 375px / 414px) — Tampilan menggunakan susunan 1 kolom secara vertikal, navigasi berderet ke bawah, dan ukuran elemen menyesuaikan lebar layar hp dengan baik.]

- Desktop: [Viewport ≥ 768px (misal 1024px / 1440px) — Bagian #home dan #about tampil bersisian 2 kolom (grid-template-columns: 1fr 1fr), sedangkan bagian #contact melebar penuh di bawahnya (grid-column: 1 / -1).]

- Galat dan perbaikan: [Terdapat ketidaksesuaian nilai atribut alt gambar dengan teks deskripsi serta kesalahan ketik teks pada label HTML, namun struktur CSS layouting berjalan secara responsif tanpa galat fungsional.]

- Validasi CSS: [Lolos validasi W3C CSS Validation Service tanpa galat syntax CSS.]
