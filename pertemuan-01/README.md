# pertemuan-01
1. *Konsep Dasar Pemrograman Web* – Dasar pembuatan website menggunakan HTML, CSS, dan JavaScript. <br>

2. *Arsitektur Klien-Peladen* – Klien (browser) mengirim permintaan, peladen (server) memproses dan mengirim respons. <br>

3. *HTTP Request dan Response* – Request adalah permintaan dari klien, sedangkan response adalah balasan dari server. <br>

4. *HTML, CSS, JavaScript, PHP, MySQL* – HTML untuk struktur, CSS untuk tampilan, JavaScript untuk interaksi, PHP untuk proses server, dan MySQL untuk penyimpanan data. <br>

5. *Hubungan Antarteknologi* – Semua teknologi saling terhubung untuk membangun aplikasi web yang dinamis dan interaktif. <br>
