# P5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Deskripsi
Dokumentasi pengembangan halaman web pada P5, meliputi JavaScript, DOM, event listener, interaksi navigasi responsif, dan validasi formulir sisi klien.

## Fitur dan Pengembangan
- Baseline P5: Menyalin artefak dari P4 ke direktori pertemuan-05/.
- Menghubungkan JS: Menghubungkan script.js eksternal ke index.html.
- Navigasi Responsif: Menambahkan event click pada tombol hamburger menu dengan classList.toggle('nav-open').
- Validasi Formulir: Menangani event submit dengan preventDefault() dan mengecek validasi masukan data.
- Umpan Balik: Menampilkan pesan error/sukses pada formFeedback serta menghapus pesan saat event reset dan input.
- Penyelarasan CSS: Menggabungkan styling P4 dengan aturan responsif dan umpan balik modul P5.

## Pengujian
- Interaksi Navigasi: Menu tersembunyi di desktop dan responsif di mobile (tombol menu dapat membuka/menutup navigasi).
- Validasi Formulir: Menampilkan pesan kesalahan warna merah jika masukan salah/kosong, dan pesan sukses warna hijau jika data valid.
- Reset & Input: Pesan umpan balik hilang otomatis saat form diketik ulang atau di-reset.
- DevTools Console: Bebas dari pesan galat/error.

## Riwayat Pengembangan
- Siapkan baseline P5 dari artefak P4
- Hubungkan JavaScript eksternal ke HTML
- Tambahkan penanganan event click
- Tambahkan penanganan event submit
- Tambahkan penanganan event reset
- Sesuaikan CSS responsif dan ID elemen HTML sesuai modul P5
- Selesaikan pengujian dan perbaikan P5
